## Общий дизайн

Тёплые кремовые панели, тёмно-бирюзовый текст, мягко объёмные кнопки с тонким бликом и тенью. Предметные рисованные иконки. Коралловый основной переход, шалфейный второстепенный, медовый подарок, лавандовая реклама. Не перегружать узорами.

Единая верхняя навигация и кошелёк. Home присутствует везде, кроме Home. Крестик страницы возвращает на Home; закрытие модальных окон сохраняет текущую логику, без её неоговорённого изменения.

## Обязательные уточнения перед реализацией

- Это визуальные предложения, не достоверные репродукции и не новый каталог музеев. Подставные картины, авторы и факты из генерации не переносить. Использовать существующий каталог проекта.
- Расположение музеев на рисунке карты приблизительное. Реальные маркеры оставить отдельными объектами и проверить по географии. Не запекать их в фон.
- Сохранить оригинальные пропорции картин, даже если генерация обрезала миниатюры.
- В галерее ровно три позиции звёзд, три колонки и прокрутка под неподвижными вкладками музеев.
- Все надписи, суммы, звёзды, кнопки, иконки и фоны — отдельные настраиваемые элементы, не полноэкранная картинка интерфейса.
- Цены и показатели на рисунках — примеры. Экономику, каталог товаров, рекламные и платёжные подключения не менять в рамках оформления.
- Уточнить описание «Без рекламы»: отключает обязательную рекламу, добровольное видео за награду остаётся.
- Вкладки верхней панели также оформить игровыми кнопками; рисунки показывают их более плоско, чем целевой вариант.
- Справа на скетче подарка показан альтернативный статус для сравнения, не вторая одновременно доступная награда.
- DEV-окно только для Editor / Development Build.
- Проблема пропавших/съехавших текстов ещё не диагностирована по скриншоту; не считать её исправленной этими скетчами.

## Промпт — общая спецификация

Use case: ui-mockup. Full-screen 16:9 landscape AIrtist approval sketch. Reference: previous gameplay mockup, style only. Warm hand-painted casual game, cream panels, softly raised rounded buttons, tangible illustrated inventory icons, restrained pastel sage/peach/honey/lavender, dark teal readable Russian labels, generous padding. No ornate trim, no phone mockup. Shared header with wallet, gift, map, gallery, store, Home and close; omit Home/close on Home. Preserve existing features. Generate individual screen compositions listed above. Modal and locked-museum variants shown as contact sheets. Correct map markers to tiny direct city icons; gallery tabs fixed above scrolling three-column grid, exactly three stars.

Реализация после утверждения: общий набор UI-элементов → поиск → Home и навигация → остальные страницы и окна → статическая проверка текста и адаптации. Play, APK и проверку игрового процесса выполняет пользователь.
