# AIrtist — реестр источников картин Лувра

Дата фиксации: 20 сентября 2026 года. Этот реестр относится только к учебному прототипу.

## Статус использования

Для локального прототипа использованы уменьшенные JPEG-версии из Wikimedia Commons. На каждой странице ниже репродукция обозначена как faithful reproduction двухмерной public-domain работы и помечена Public Domain Mark. Это рабочая фиксация источника, а не самостоятельное юридическое заключение для коммерческого релиза: перед выпуском требуется отдельная проверка прав для территорий распространения, магазина и маркетинговых материалов.

## Правило обновления

При замене файла нужно обновить строку реестра, проверить метку прав на странице первоисточника и повторно провести юридическую проверку перед включением в релизную сборку.
